# Tamilselvan R Portfolio

A modern, responsive portfolio inspired by the clean dark aesthetic of the reference portfolio.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — animations and cursor glow
- `resume.pdf` — add your own resume PDF here

## Before deploying
1. Replace `your-email@example.com` in `index.html` with your email.
2. Replace the LinkedIn `#` link with your LinkedIn profile.
3. Put your resume PDF in this folder and name it `resume.pdf`.
4. Update project GitHub/demo links if you have them.

## Deploy on Vercel
Option A: Drag/upload the project folder to a GitHub repository, then import the repository in Vercel.

Option B: Use Vercel's CLI:
`vercel`

This is a static HTML/CSS/JS site, so no build command is required.
